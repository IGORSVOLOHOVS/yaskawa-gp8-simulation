# Installation Guide

## System Requirements
- Linux (RedHat / Fedora / Ubuntu / Debian)
- C++23/C++26 Compiler (GCC 15+ / Clang 18+)
- CMake 3.14+
- Eigen3 (`libeigen3-dev`)

## Building and Installing

Run the unified CLI script:
```bash
./robot init
./robot build release
./robot install
```

Installed binaries will be placed into `./install/bin/`.
